# Login Page – React

## 📌 Project Overview
This project is a **simple login page built using React**.  
It was created as **Project 1** to learn and understand the **fundamentals of React**, including components, state, and event handling.

- CSS

- Input handling using React state

- Component-based structure

## 🎯 Learning Outcomes

- State and event handling
